## B. 있으면 훨씬 수월한 것

| 품목 | 왜 |
|---|---|
| 전동드릴 또는 송곳 + 줄 | 물통 측면에 플로트 스위치 구멍 뚫기. 없으면 인두기로 녹여 뚫어도 되지만 냄새 남 |
| 분무기 | 씨앗 화분 발아기 급수. 물뿌리개로 부으면 씨앗이 쓸려감 |
| 케이블 타이 | 튜브와 전선 고정. 튜브가 움직이면 급수 위치가 바뀜 |
| 방수 테이프 / 절연 테이프 | 물통 근처 배선 마감 |
| 빨래집게 또는 튜브 클립 | 튜브 토출구를 화분 가장자리에 고정 |
| CR2032 배터리 | HHCC용. 동봉돼 있을 가능성이 높으니 먼저 확인 |
| 브레드보드 전원 레일 점퍼 | GND 공통 결선을 깔끔하게 |

## C. Stage 2에서 실패했을 때만 사는 것

미리 살 필요 없습니다. AOD4184가 3.3V로 완전히 안 켜질 때만 필요합니다.

| 품목 | 용도 |
|---|---|
| 로직레벨 MOSFET 모듈 (IRLZ44N 등) | 3.3V로 완전 도통되는 대체품 |
| 레벨시프터 모듈 (3.3V→5V) | 기존 AOD4184를 5V 게이트로 구동 |

## D. 사지 않아도 되는 것

| 품목 | 이유 |
|---|---|
| CCTV·IP카메라 | 보유한 USB 웹캠으로 충분. 카메라 자체가 이번 파일럿 후순위 |
| 유량계 | 급수량은 시간 기반 추정으로 충분. 파일럿에 과함 |
| 릴레이 모듈 | MOSFET이 이미 있음. 릴레이는 수명·소음 면에서 열위 |
| 라즈베리파이 | 맥이 게이트웨이 역할을 함 |
| 자동급수 타이머 콘센트 | 제어를 펌웨어가 하는 것이 이 프로젝트의 목적 |

## 구매 순서 제안

Stage 순서에 맞춰 나눠 사면 낭비가 없습니다.

1. **지금 바로**: 멀티미터, 10kΩ 저항, 12V 어댑터(H3 확인 후), DC 잭 변환, 전선 → Stage 0~2 진행 가능
2. **Stage 2 통과 후**: 물통, 계량컵 → Stage 3~4 진행 가능
3. **Stage 8 통과 후**: 화분, 흙, 모종, 씨앗 → Stage 9 진행 가능

모종을 먼저 사면 시스템이 준비되기 전에 식물부터 관리해야 합니다. **모종은 안전 검증이 끝난 뒤에 사는 것을 권장합니다.**
